# SPENTA — Intelligent Reality | Investor Master SSOT
## Granular Visual Design, Dark/Light Theme Parity, Animation & Section-by-Section Architecture (`design.md`)

> **Purpose**: Exact, implementation-grade design and motion specification extracted from the **Spenta Intelligent Reality Investor Master SSOT** codebase, tailored to replicate its dark obsidian visual language, typography, color hierarchy, interactive mechanics, and **dual Light/Dark mode animation system** inside **"Remix Spentech Pitching WebApp"**.

---

## 1. Visual Philosophy & Atmospheric Layering

The aesthetic is **Institutional Aerospace Telemetry meets Venture Capital Diligence**: a razor-sharp, high-density obsidian interface (`#05070B`) punctuated by controlled bioluminescent accents (Cyan, Emerald, Indigo, Purple), micro-grid textures, precision corner reticles (`.hud-corner`), tabular monospace metrics, and calm, physics-calibrated motion (`cubic-bezier(0.16, 1, 0.3, 1)`).

### 1.1 Alternating Surface Elevation Stack (Dark Mode)
Sections alternate deliberately between two ultra-deep obsidian values (`#05070B` and `#070A10` / `#0A0F16`) separated by hairline `slate-800/80` borders and animated `SectionDivider` beams so vertical scrolling feels rhythmically structured without heavy card walls:

| Layer Level | Hex / Tailwind Token | Usage |
| :--- | :--- | :--- |
| **L0: Abyssal Base** | `#020617` (`body`), `#030407` (`#main-footer`), `#030508` (`GlobalLoadingScreen`) | Page canvas, footer foundation, boot splash |
| **L1: Primary Obsidian** | `#05070B` | Root `<div id="app-root">`, `#hero`, `#fusion-stack`, `#rd-roadmap`, `#value-exchange`, `#case-studies`, `#executive-team`, `#passive-ip`, `#investment-terms` |
| **L2: Elevated Obsidian** | `#06090F` (`InvestorNewsTicker`), `#070A10`, `#0a0f16` (`MilestonesSection`) | Alternating sections (`#dual-engines`, `#market-shift`, `#unit-economics`, `#dual-shore-globe`, `#moat-benchmarks`), `BreadcrumbNav` (`#070A10/95`), sticky headers |
| **L3: Glass Cards & Modals** | `bg-slate-950/85` – `bg-slate-950/95`, `#0B101B` | Primary cards, floating rails (`bg-slate-950/92 backdrop-blur-xl`), modal containers (`backdrop-blur-2xl`) |
| **L4: Interactive Controls** | `bg-slate-900/60` – `bg-slate-900/95` | Nested metric tiles, tab bars, hover card elevation, active pill backgrounds |
| **Hairline Borders** | `border-slate-800/80` (rest), `border-slate-700/80` (hover/elevated) | All structural dividers, card outlines, input frames |

> **Dark Mode Implementation Nuances for "Remix Spentech Pitching WebApp"**:
> 1. **Never rely on pure `#000000` or flat `#111827`**: Alternate `#05070B` and `#070A10` with `border-t border-b border-slate-800/80` and `10%`-opacity radial blur orbs (`blur-[120px]` to `blur-[180px]`).
> 2. **Always invert pill badge opacities in dark mode**: Dark badges use `bg-{color}-950/60 border border-{color}-500/30 text-{color}-300` (whereas light mode uses `bg-{color}-50 border-{color}-200 text-{color}-700`).
> 3. **D3 & Recharts SVG colors must read CSS variables or dark flags**: Axis strokes `#334155` (dark) / `#CBD5E1` (light); tick labels `#94A3B8` (dark) / `#475569` (light) in `10px` `JetBrains Mono`.
> 4. **Interactive rings use offset matching the obsidian canvas**: `ring-2 ring-cyan-400 ring-offset-4 ring-offset-[#05070B]` (light mode uses `ring-offset-white` or `ring-offset-slate-50`).
> 5. **Print Override (`@media print`)**: Always force `#ffffff` canvas, `#020617` headings, `#334155` body text, `filter: none !important`, disable `backdrop-filter` / animations / HUD brackets, and hide all `header, nav, aside, .fixed, .sticky, .floating-sidebar, .section-divider, #main-footer`.

6. Checklist for Porting Dark Mode & Dual-Theme Animations to "Remix Spentech Pitching WebApp"
Wrap Theme Tokens in CSS Custom Properties: Map all #05070B / #070A10 / slate-950 / slate-800 surfaces and light equivalents to semantic tokens so switching Light ↔ Dark updates cards, .bg-grid-pattern, .hud-corner, .crt-scanlines, .service-card-3d, and D3/Recharts axes automatically.
Use INSTITUTIONAL_EASE = [0.16, 1, 0.3, 1] Everywhere: Keep Motion entrances understated (y: 18–28px, duration: 0.5–0.65s, viewport={{ once: true }}) so enterprise diligence feels authoritative rather than bouncy.
Calibrate Glow Alpha by Mode: Keep neon drop-shadow / box-shadow glows at 0.35–0.65 alpha in Dark Mode and tone them down to 0.14–0.30 crisp elevation shadows in Light Mode.
Enforce tabular-nums, whitespace-nowrap, & Disabled Loading States: Every numeric counter, KPI metric, and chart tooltip uses JetBrains Mono + tabular-nums; every async button (PDF, .PPTX, Summary, AI Thesis, Monte Carlo) displays a localized Loader2 animate-spin and sets disabled while running.
Respect Accessibility & Print: Keep focus-visible:ring-2 focus-visible:ring-cyan-400, @media (prefers-reduced-motion: reduce), safe-area insets (env(safe-area-inset-*)) on fixed rails, and clean white-paper @media print overrides.
